Bruno AI Project Overview

Executive Summary

Bruno AI is an innovative mobile application designed to serve as a collaborative assistant for everyday food-related tasks. Built around a friendly, fictional bear character named Bruno, the app leverages advanced AI agent architecture to help users manage groceries, track food inventory, and prepare meals efficiently. By emphasizing user-driven interactions, Bruno AI acts as a supportive partner rather than a prescriptive guide, adapting to individual preferences and needs without imposing external agendas like health-focused recommendations. The project evolves from previous versions with a streamlined V3.0 agent system, incorporating modern AI frameworks for seamless collaboration and real-time responsiveness. As of July 10, 2025, this overview captures the project's core elements, including its goal, features, technical foundation, and future potential.

Project Goal and Objectives

The primary goal of Bruno AI is to assist users with grocery shopping, food management, and meal preparation in a collaborative, empowering way. Unlike traditional apps that dictate plans or prioritize specific outcomes (e.g., nutrition), Bruno AI focuses on listening to and delivering on what users explicitly want—whether that's building a budget-friendly shopping list, suggesting ways to use existing pantry items, or providing quick prep ideas for a busy week. This user-centric approach fosters a sense of teamwork, making users feel like they're working alongside a reliable companion to simplify daily routines.

Key Objectives:

  • Collaborative Assistance: Enable real-time, adaptive support where Bruno queries user preferences (e.g., "What items do you want to prioritize?") and refines outputs based on feedback.
  • Practical Delivery: Streamline tasks like one-click Instacart shopping, inventory tracking, and meal prep without forcing changes—empowering users to manage food on their terms.
  • Accessibility and Efficiency: Target budget-conscious families, students, and professionals with affordable, intuitive tools that save time and reduce waste.
  • Scalability and Innovation: Build a modular system that evolves with user needs, aiming for high retention (e.g., 70% week-1) through responsive, non-intrusive interactions.

Success is measured by user engagement metrics (e.g., session duration >10 minutes, 15% Instacart conversion), satisfaction (90%+ positive feedback on adaptability), and operational efficiency (response times <1.5s, 25%+ cost savings via optimizations).

Key Features

Bruno AI offers a suite of integrated features powered by AI agents and external services:

  • Grocery Shopping Support: Real-time pricing and list creation via Instacart API, with deep links for seamless ordering. Users can specify wants (e.g., "under $50, focus on staples"), and Bruno adapts dynamically.
  • Food Management: AI-driven pantry tracking, expiration predictions, and waste reduction suggestions. Collaborative elements include user input for custom organization (e.g., "Prioritize these items").
  • Meal Preparation Assistance: Practical recipe generation and prep ideas tailored to user inputs, such as available ingredients or time constraints, without health mandates.
  • Conversational Interface: Mobile app with voice/text chat, real-time streaming, and feedback loops for iterative refinement.
  • Budget and Customization Tools: Predictive spending forecasts and personalization, always confirming user wants (e.g., "Does this match your preferences?").
  • Integration and Extensibility: Seamless with Instacart for shopping; expandable via APIs for future tools like smart kitchen devices.

V3.0 Agent System

The V3.0 architecture represents a significant evolution, adopting a hybrid mesh-workflow topology using Google's Agent Development Kit (ADK) for orchestration, Agent2Agent (A2A) Protocol for peer-to-peer collaboration, and Model Context Protocol (MCP) for structured tool integration. This design eliminates the central Master Agent from previous versions, reducing bottlenecks and enabling distributed, scalable interactions. Agents are built as ADK LlmAgents (powered by Gemini models), with workflow agents (e.g., ParallelAgent for concurrent tasks) handling dynamic orchestration.

Core Agents (5 LlmAgents)

Each agent is modular, collaborative, and user-focused, using A2A for direct peer communication (e.g., JSON-RPC over HTTP) and MCP for tool access (e.g., Instacart API calls).

  1. Pantry Manager Agent (Gemini-2.5-flash-lite): Tracks inventory and suggests uses based on user wants; collaborates via A2A with Instacart for replenishment.
  2. Instacart Integration Agent (Gemini-2.5-flash-lite): Handles pricing, lists, and orders; uses MCP for API structure and A2A for real-time updates.
  3. Recipe Chef Agent (Gemini-2.5-flash): Generates prep ideas adapted to user-specified ingredients/time; peers with Budget via A2A.
  4. Budget Analyst Agent (Gemini-2.5-flash): Forecasts and optimizes costs per user limits; integrates MCP for analytics tools.
  5. Reflection & Feedback Agent (Gemini-2.5-flash): Reviews outputs, gathers user input (e.g., "How can we adjust this?"), and iterates for better alignment—added in V3.0 for enhanced collaboration.

Orchestration and Infrastructure

  • Gateway Workflow Agent (ADK ParallelAgent): Entry point that spawns parallel/sequential flows (e.g., pantry check + budgeting simultaneously).
  • Communication: A2A for task/messages (with Agent Cards for discovery); SSE streaming for live feedback.
  • Data Layer: Redis/PostgreSQL for caching (85% hit ratio); ML models for predictions.
  • Enhancements: Token Optimizer module (via ADK CustomAgent) for 20-30% savings by compressing prompts and model routing.
  • Deployment: ADK on Vertex AI for auto-scaling; Kubernetes-ready.

This system achieves ~30% faster responses and 99%+ reliability, focusing on collaborative delivery (e.g., agents adapt via user queries).

Bruno's Personality: The Wise Culinary Bear

Bruno is portrayed as a professional yet characterful bear—a thoughtful strategist with a warm, bear-like charm. His voice is confident and practical, with subtle whimsy (e.g., "As a bear who's foraged many a deal...") to make interactions feel like talking to a real, helpful bear. He prioritizes user wants, asking clarifying questions and adapting without judgment.

Technical Stack and Improvements

  • Frameworks: ADK (agent building/orchestration), A2A (collaboration), MCP (tools like Instacart API).
  • Improvements: Token management via optimizer (reduces multi-agent overhead); Reflection Agent for feedback loops; Cost analytics for 25%+ savings.
  • Monitoring: ADK evaluation framework for metrics like task success (95% target).

Future Roadmap

  • Medium-term: Add agents for sustainability or personalization.
  • Long-term: Expand to smart home integrations and international grocery partners.
