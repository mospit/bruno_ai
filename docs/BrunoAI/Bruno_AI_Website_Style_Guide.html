Comprehensive Website Style Guide for Bruno AI

This style guide establishes the visual, interactive, and experiential standards for the Bruno AI single-page website, ensuring consistency, accessibility, and alignment with the app's collaborative, user-empowering ethos. It builds on the provided HTML code, incorporating 2025 web design trends like fluid animations, dark mode support, and AI-optimized personalization for better engagement. The guide is LLM-friendly: Use sections as prompts (e.g., "Generate a hero section following Bruno AI website style guide's color and typography rules"). Focus on mobile-first responsiveness (e.g., Tailwind classes), SEO readiness, and performance (<2s load).

Key Principles

  • Collaborative Warmth: Designs evoke Bruno's bear personality—welcoming, practical, with subtle whimsy (e.g., rounded elements like fur).
  • User-Centric Simplicity: Clean layouts prioritizing content; intuitive navigation for quick downloads.
  • Accessibility & Inclusivity: WCAG 2.2 AA compliant (contrast >4.5:1, keyboard nav, ARIA labels).
  • Performance: Lazy-loading, minified assets, CDN usage.
  • Cross-Browser: Support Chrome, Safari, Firefox, Edge (2025 versions).
  • Tech Stack: HTML5/CSS3/JS; Tailwind for utilities; Font Awesome for icons; No heavy frameworks unless needed (e.g., React for dynamic if expanding).

Branding and Identity

  • Logo Usage: Primary: Bear with hat/apron (provided PNG/SVG, 512x512 min). Place in nav (40x40px left). Variants: Icon-only (no text, for favicons); Full with "Bruno AI" (horizontal, Roboto Bold 24px #8B4513).
  • Mascot (Bruno): Appear in hero (300x300px, wave animation); limit to 15% of elements. Alt text: "Bruno bear mascot."
  • Tagline: "Your Collaborative Kitchen Companion" – Use in hero (32px Italic #333); short form: "Team Up with Bruno."
  • Voice/Tone: Practical, warm (e.g., "Let's build your list together"). For copy: 16px Regular #333; max 60 chars/line.
  • Favicon: 32x32 PNG of bear head; Apple-touch: 180x180.
  • For LLM: "Generate nav with logo: 40x40 bear icon left, tagline 24px Bold Warm Brown."

Accessibility and Performance

Accessibility

  • ARIA (e.g., aria-label on buttons)
  • Contrast >4.5:1
  • Keyboard focus (outline Green)
  • Alt text/images
  • Screen reader friendly (e.g., semantic HTML)

Performance

  • Lazy-load images (loading=lazy)
  • Minify CSS/JS (Tailwind production)
  • CDN for fonts/icons
  • Service worker for caching (Workbox free)

SEO

  • Meta tags (as in code)
  • Structured data (JSON-LD for app)
  • Sitemap.xml
  • Robots.txt allow all

For LLM: "Ensure accessibility: Add aria-label to icons; Lazy-load images."
