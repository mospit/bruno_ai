Bruno AI Style Guide

1. Introduction

This style guide defines the visual, interactive, and tonal standards for the Bruno AI mobile app, ensuring a consistent, intuitive, and user-empowering experience. Designed for cross-platform use (iOS/Android), it draws from 2025 best practices in mobile UI/UX, emphasizing minimalism, personalization, and accessibility for collaborative apps like grocery shopping and meal prep tools.

The guide is comprehensive for LLM implementation and should be used as a reference prompt for generating screens, text, or components. For example: "Generate a dashboard card following the Bruno AI style guide's typography and color rules."

Key Principles

  • User-Centric Empowerment: Designs prioritize collaboration, adapting to user wants without overwhelming elements. Favor clean layouts with gesture support for intuitive flows.
  • Bear-Inspired Warmth: Subtle whimsy (e.g., rounded shapes evoking Bruno's fur) balanced with professionalism for a "talking bear" feel.
  • Accessibility First: High contrast, scalable text, and voice integration for inclusivity.
  • Cross-Platform Consistency: Follow Material Design 3 (Android) and Human Interface Guidelines (iOS) hybrids with rounded components, fluid animations, and adaptive layouts.
  • Trends 2025: Voice-first interactions, AI-driven personalization, and eco-friendly subtle animations.

2. Branding and Identity

Logo and Mascot

  • Logo: A stylized bear face (Bruno) with a subtle apron, in Warm Brown (#8B4513). Variants include full logo with name in sans-serif font and icon-only version for app icon.
  • Tagline: "Your Collaborative Kitchen Companion" – Used in onboarding and marketing materials.
  • Mascot Usage: Bruno appears in headers/chat as a smiling avatar and in subtle animations (e.g., paw wave for loading). Limit to 20% of UI to maintain professionalism.
  • App Icon: Bear face on Soft Beige background, with green accent for Instacart tie-in.

Voice and Tone

Bruno embodies a warm, professional bear persona that is confident, adaptive, and questioning. The voice should avoid slang and use collaborative language such as "we" and "let's" to foster partnership. Sentence length should be kept short for readability (15-25 words maximum).

For LLM implementation: "Generate text in Bruno's voice: Warm, practical, user-focused, with subtle bear charm like 'my bear instincts say...'."

3. Color Palette

A nature-inspired color scheme designed for warmth and approachability, with high contrast meeting WCAG AA compliance standards.

Primary Colors

Color Hex Code Usage
Warm Brown #8B4513 Headers, buttons, Bruno elements, chat bubbles
Instacart Green #43B02A Action buttons, progress bars, "Add to Cart" functions

Secondary Colors

Color Hex Code Usage
Soft Beige #D2B48C Backgrounds, cards
Deep Forest Green #228B22 Icons, borders in pantry/shopping sections

Accent Colors

Color Hex Code Usage
Golden Yellow #FFD700 Highlights, deals, positive feedback
Error Red #FF4500 Warnings and error states (softened for non-alarm)

Usage Guidelines

  • Limit to 3-4 colors per screen
  • Use gradients sparingly (brown to green for transitions)
  • Dark mode: Invert to darker brown (#5A3A1F) primaries with lighter accents
  • For LLM: "Apply color palette: Use Warm Brown for accents, ensure contrast ratio greater than 4.5:1"

4. Typography

Sans-serif fonts are used throughout for modern readability, with scalable text sizes (minimum 16px base size).

Font Family

  • Primary: Roboto (Android) or SF Pro (iOS) for platform consistency
  • Fallback: System sans-serif fonts

Typography Hierarchy

Element Size Weight Color Usage
Headings (H1) 24px Bold Warm Brown Screen titles
Subheadings (H2) 18px Medium Warm Brown Card titles, section headers
Body Text 16px Regular Dark Gray (#333333) Descriptions, general content
Captions 14px Light Medium Gray Timestamps, tags, metadata
Button Text 16px Bold White Action buttons on colored backgrounds

Formatting Guidelines

  • Line height: 1.5x font size for optimal readability
  • Letter spacing: 0.5% for improved legibility
  • Text alignment: Left-aligned for body text
  • Emphasis: Use bold sparingly for important information
  • For LLM: "Use typography: H1 for titles in 24px Bold Warm Brown; ensure body text is 16px with 1.5 line height"

5. Icons and Imagery

Icon Style

  • Style: Line icons with rounded edges, 24-48px size range
  • Colors: Deep Forest Green or Warm Brown for consistency
  • Theme: Bear-themed where appropriate (e.g., paw print for pantry)
  • Icon Set: Use Material Icons for cross-platform consistency

Key Application Icons

Function Icon Description
Home House Dashboard/main screen navigation
Chat Speech bubble Conversation with Bruno
Pantry Refrigerator/Paw print Food inventory management
Shopping Shopping cart Grocery list and purchasing
Prep Plate/Utensils Meal preparation and recipes

Imagery Guidelines

  • Use high-resolution photos for food items and recipes
  • Bruno illustrations should maintain earthy, natural styling
  • Avoid stock imagery in favor of realistic, user-generated content
  • All images must include appropriate alt text for accessibility
  • Icons should be scalable vector format (SVG) for crisp rendering

Animation Guidelines

  • Subtle animations with 300ms ease-in timing
  • Cart shake animation for adding items
  • Bruno-specific animations: paw wave for loading states
  • Keep animations minimal and purposeful

6. UI Components

Buttons

  • Primary Buttons: Instacart Green background, white text, 8px border radius
  • Secondary Buttons: Warm Brown outline, brown text, transparent background
  • States: Hover (lighten by 10%), Disabled (grayed out), Active (slightly darker)
  • Sizing: Minimum 44px height for touch accessibility

Cards

  • Background: Soft Beige with 16px border radius
  • Shadow: Subtle 2px shadow for depth
  • Expandable: Include chevron icon for collapsible content
  • Padding: 16px internal padding for content

Progress Indicators

  • Progress Bars: Horizontal layout, Instacart Green fill on Light Gray track
  • Labels: Percentage or fraction display in bold text
  • Loading States: Animated Bruno paw or simple spinner

Input Fields

  • Style: Rounded fields with clear placeholder text
  • Icons: Voice and photo upload icons positioned inside field
  • Focus States: Warm Brown border highlight
  • Validation: Clear error messaging with Error Red color

Modal Dialogs

  • Size: 80% of screen width, center-positioned
  • Controls: Close X button and confirm/cancel actions
  • Background: Semi-transparent overlay for context

7. Layout and Navigation

Grid System

  • Base Unit: 8px for consistent spacing
  • Margins: 16px side margins, 8px between elements
  • Responsive Design: Adapt from grid to list view on smaller screens
  • Breakpoints: Design for phone, tablet, and landscape orientations

Navigation Structure

  • Bottom Tab Bar: Maximum 5 primary navigation items
  • Overflow Menu: Hamburger menu for additional options
  • Deep Linking: Direct navigation from chat to relevant screens
  • Back Navigation: Clear breadcrumb trail and back button placement

Screen Flow

  • Home Hub: Central dashboard with quick access to all functions
  • Task-Based Flow: Logical progression from planning to execution
  • Context Switching: Seamless movement between related tasks

8. Interactions and Gestures

Gesture Support

  • Swipe: Left/right for tab navigation, up/down for item deletion
  • Drag and Drop: Reorder items in lists and move between categories
  • Pinch Zoom: Scale images and detailed views
  • Pull to Refresh: Update content in list views

Animation Specifications

  • Micro-animations: 200ms fade-in for cards and content
  • Transitions: Ease-out curve for natural feeling
  • Loading States: Bruno paw animation with gentle bounce
  • Feedback: Subtle scale animation for button presses

Haptic Feedback

  • Tap Confirmation: Light haptic feedback for button presses
  • Success Actions: Medium haptic for completed tasks
  • Error States: Distinct haptic pattern for warnings

9. Accessibility Standards

Compliance Requirements

  • WCAG 2.2 AA: Meet or exceed accessibility guidelines
  • Dynamic Text: Support text scaling up to 200% without loss of functionality
  • Screen Reader: Full VoiceOver and TalkBack support with descriptive labels
  • Contrast Ratios: Minimum 4.5:1 for normal text, 3:1 for large text

Inclusive Design Features

  • Color Blindness: Use patterns and textures in addition to color coding
  • Motor Accessibility: Minimum 44px touch targets for all interactive elements
  • Cognitive Accessibility: Clear, simple language with consistent navigation
  • Voice Navigation: Full voice control capability for hands-free operation

Implementation Guidelines

  • Alt Text: Descriptive alternative text for all images and icons
  • Focus Management: Logical tab order and clear focus indicators
  • Error Prevention: Clear validation and confirmation dialogs
  • Multiple Input Methods: Support for voice, text, and touch input

10. Cross-Platform Consistency

iOS Adaptations

  • Follow Human Interface Guidelines for navigation patterns
  • Use SF Pro font family for text rendering
  • Implement iOS-specific gestures (edge swipe for back navigation)
  • Adapt button styles to iOS conventions while maintaining brand colors

Android Adaptations

  • Follow Material Design 3 principles for component behavior
  • Use Roboto font family for optimal Android rendering
  • Implement floating action buttons where appropriate
  • Utilize Android-specific navigation patterns (bottom sheets, navigation drawer)

Responsive Design

  • Portrait Mode: Primary design orientation with vertical scrolling
  • Landscape Mode: Adaptive layout with horizontal space utilization
  • Tablet Support: Expanded layouts with multi-column arrangements
  • One-Handed Use: Important controls within thumb reach
