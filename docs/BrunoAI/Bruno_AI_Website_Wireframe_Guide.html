Detailed Wireframe for the Bruno AI Single-Page Website

Below, I provide a comprehensive wireframe for the Bruno AI website based on the provided HTML code and the app's collaborative theme. The design is a vertical-scrolling single-page application (SPA) with smooth transitions, optimized for desktop (1440px wide) and mobile (375px wide) views. I've used text-based ASCII art to visualize layouts for each section, followed by detailed descriptions of elements, interactions, dimensions, colors (from style guide), and rationale. This ensures clarity for implementation in tools like Figma or code.

The overall structure is linear: Hero → Features → How It Works → Testimonials → Newsletter → Download/Footer. Navigation is top-fixed with anchors. Total height ~4000px desktop; responsive with media queries (e.g., stack on mobile). Colors: Warm Brown #8B4513 accents, Instacart Green #43B02A CTAs, Soft Beige #D2B48C bgs.

Details:

  • Elements: Logo (bear icon, #8B4513 text, 40px); Links (sans-serif 16px, #333 hover #43B02A); Toggle (rounded switch, brown circle).
  • Interactions: Smooth scroll on links (JS); Hamburger opens slide-in menu (300ms animation, beige bg); Dark mode flips vars (e.g., bg #1A1A1A).

  • Rationale: Sticky for easy nav; dark mode for accessibility (40% users prefer).
