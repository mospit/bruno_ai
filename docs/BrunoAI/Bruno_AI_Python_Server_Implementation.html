Comprehensive Guide to Implementing the Python Server for Bruno AI

This guide provides a step-by-step implementation for the Bruno AI backend server, serving as the core for the mobile app's multi-agent system. It focuses on coding with Python 3.12+, integrating PydanticAI for agents, FastA2A for A2A protocol, Claude models (Sonnet 4 for complex reasoning, Haiku for efficiency), Redis/Postgres for data/memory, and Instacart API for tools. The server handles collaborative tasks (e.g., user queries like "$200 Caribbean meals"), ensuring user-driven adaptation without prescription. Assumes DIY coding; designed for serverless deployment (GCP Cloud Run as recommended) for scalability.

The backend exposes A2A endpoints for app communication, manages state/token efficiency, and scales to 10K+ users. Total dev time: 20-40 hours; costs: <$200/mo operational.

1. Overview and Architecture

Purpose

Orchestrate 5 agents via PydanticAI, expose as A2A servers with FastA2A, persist data in Redis/Postgres, and integrate Instacart via tools. Supports async, token-optimized flows for low-latency collaboration.

Key Components

  • Agents: PydanticAI with Claude
  • Protocol: FastA2A for JSON-RPC/A2A
  • Tools: Custom functions (MCP-like) for Instacart/DB
  • Memory: Redis caching, Postgres persistence (per memory guide)
  • Token Management: Compression/routing (per token guide)

Technology Stack

Uvicorn (ASGI server), Pydantic for validation, Anthropic SDK for Claude, Redis/Postgres clients.

Assumptions

Environment variables for keys (e.g., .env with ANTHROPIC_API_KEY, INSTACART_KEY).

3. Implementing Agents (PydanticAI with Claude)

Define 5 agents; use Haiku/Sonnet allocation. Add token compression wrapper.

Base Agent Wrapper (for token management/memory)

from pydantic_ai import Agent
from anthropic import Client
from redis import Redis
from dotenv import load_dotenv
import os

load_dotenv()
haiku_client = Client(model="claude-3.5-haiku")  # For compression
r = Redis.from_url(os.getenv('REDIS_URL'))

def token_optimized_agent(model, instructions):
    def compress_context(context):
        return haiku_client.summarize(context, "Compress keeping user wants like budget/cuisine")

    def cached_wrapper(query, context_id):
        key = f"cache:{context_id}:{hash(query)}"
        if cached := r.get(key):
            return cached.decode()
        compressed = compress_context(query)  # Token save
        agent = Agent(model, instructions=instructions)
        result = agent(compressed)
        r.set(key, result, ex=3600)
        return result
    return cached_wrapper

4. Tools Implementation (MCP-Like in PydanticAI)

Wrap Instacart/DB as tools with schemas.

Instacart Tool (API Wrapper)

from pydantic_ai import Tool
import requests
from os import getenv

class InstacartTool(Tool):
    schema = {
        "name": "instacart_query",
        "parameters": {"items": "array", "budget": "number"},
        "returns": {"total": "number", "list": "array"}
    }
    def run(self, items, budget):
        response = requests.post("https://api.instacart.com/v1/search", 
                               json={"items": items}, 
                               headers={"Authorization": getenv('INSTACART_API_KEY')})
        data = response.json()
        # Process for budget check
        total = sum(item['price'] for item in data)
        if total > budget:
            return {"total": total, "list": data, "note": "Over budget - suggest subs"}
        return {"total": total, "list": data}

# Attach to agent: recipe_chef.tools = [InstacartTool()]

Database Tool (Postgres for Preferences)

import psycopg2
class DBTool(Tool):
    schema = {"name": "db_query", "parameters": {"user_id": "string", "action": "string"}, "returns": "object"}
    def run(self, user_id, action):
        conn = psycopg2.connect(os.getenv('POSTGRES_URL'))
        cur = conn.cursor()
        if action == "get_preferences":
            cur.execute("SELECT preferences FROM users WHERE id = %s", (user_id,))
            return cur.fetchone()[0]
        conn.commit()
        cur.close()
        conn.close()

5. Server Implementation (FastA2A with Uvicorn)

Expose agents as A2A endpoints; add auth/monitoring.

Main Server File (app.py)

from fasta2a import to_a2a, RedisStorage
from uvicorn import run
from starlette.middleware.authentication import AuthenticationMiddleware
from jose import jwt
import os

# Agents from above
agents = {
    'pantry': pantry_manager,
    'instacart': instacart_integration,
    'recipe': recipe_chef,
    'budget': budget_analyst,
    'reflection': reflection_feedback
}

# JWT Auth Middleware
class JWTBackend:
    async def authenticate(self, request):
        token = request.headers.get('Authorization')
        if token:
            payload = jwt.decode(token.split()[1], os.getenv('SECRET_KEY'))
            return True, payload
        return False, None

# Create A2A apps per agent
apps = {}
storage = RedisStorage.from_url(os.getenv('REDIS_URL'))
for name, agent in agents.items():
    app = to_a2a(agent, storage=storage)
    app.add_middleware(AuthenticationMiddleware, backend=JWTBackend())
    apps[name] = app

# Gateway Endpoint (Chain Agents)
from pydantic_ai import chain
@apps['gateway'].post("/query")
async def gateway_query(request):
    # Chain example: pantry >> instacart >> recipe
    result = chain(pantry_manager >> instacart_integration >> recipe_chef)(request.body)
    return result

if __name__ == "__main__":
    run("app:apps['gateway']", host="0.0.0.0", port=8000)  # Run gateway; others on different ports if needed

12. Security Implementation

Authentication & Authorization

from starlette.middleware.authentication import AuthenticationMiddleware
from jose import jwt

def jwt_auth(request):
    token = request.headers.get('Authorization')
    if not token:
        raise Exception("Unauthorized")
    claims = jwt.decode(token.replace('Bearer ', ''), 'secret_key')
    return claims['user_id']

app.add_middleware(AuthenticationMiddleware, backend=jwt_auth)

Data Encryption

from cryptography.fernet import Fernet
import redis

key = Fernet.generate_key()
f = Fernet(key)
r = redis.Redis(ssl=True)  # TLS enabled

def secure_set(k, v):
    encrypted = f.encrypt(v.encode())
    r.set(k, encrypted)

def secure_get(k):
    encrypted = r.get(k)
    return f.decrypt(encrypted).decode() if encrypted else None

13. Error Handling and Resilience

Circuit Breaker Pattern

import time
from functools import wraps

def circuit_breaker(failure_threshold=5, recovery_timeout=60):
    def decorator(func):
        func.failure_count = 0
        func.last_failure_time = None
        func.state = 'CLOSED'  # CLOSED, OPEN, HALF_OPEN
        
        @wraps(func)
        def wrapper(*args, **kwargs):
            if func.state == 'OPEN':
                if time.time() - func.last_failure_time > recovery_timeout:
                    func.state = 'HALF_OPEN'
                else:
                    raise Exception("Circuit breaker is OPEN")
            
            try:
                result = func(*args, **kwargs)
                if func.state == 'HALF_OPEN':
                    func.state = 'CLOSED'
                    func.failure_count = 0
                return result
            except Exception as e:
                func.failure_count += 1
                func.last_failure_time = time.time()
                if func.failure_count >= failure_threshold:
                    func.state = 'OPEN'
                raise e
        return wrapper
    return decorator

15. Monitoring and Analytics

Performance Monitoring

import time
import logging
from functools import wraps

def monitor_performance(func):
    @wraps(func)
    async def wrapper(*args, **kwargs):
        start_time = time.time()
        try:
            result = await func(*args, **kwargs)
            duration = time.time() - start_time
            logging.info(f"{func.__name__} completed in {duration:.2f}s")
            return result
        except Exception as e:
            duration = time.time() - start_time
            logging.error(f"{func.__name__} failed after {duration:.2f}s: {e}")
            raise
    return wrapper
