# Bruno AI Website

A warm, friendly one-page website for Bruno AI - the budget-savvy bear who helps families plan delicious meals within any budget using real grocery prices and instant Instacart shopping.

## 🐻 About Bruno AI

Bruno AI is an innovative AI-powered food budget planning application that combines:
- **Budget-first meal planning** using real grocery store prices
- **AI personality** that learns and cares about your family's preferences  
- **One-click Instacart integration** for seamless grocery shopping
- **Multi-agent architecture** using Google's A2A protocol

## 🎨 Website Design Philosophy

This website embodies Bruno's personality and values:

### Design Principles
- **Warm & Approachable**: Earth tones, friendly typography, bear-themed elements
- **Budget-Conscious**: Clear value propositions and savings emphasis
- **Family-Oriented**: Content focused on family needs and real user stories
- **Trustworthy**: Social proof, testimonials, and transparent benefits

### Visual Identity
- **Primary Colors**: Warm browns (#8B4513, #A0522D) representing Bruno's bear nature
- **Secondary Colors**: Instacart green (#43B02A) for shopping elements
- **Accent Colors**: Warm yellow/orange for highlights and success states
- **Typography**: Nunito for headings (friendly, approachable), Inter for body text (readable)

## 🌟 Features

- **Animated Bruno Character**: Click Bruno to see different quotes and sparkle effects

## 🚀 Getting Started

1. **Open the website**: Simply open `index.html` in any modern web browser
2. **Local server** (recommended): Use a local server for best experience:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```
3. **Navigate to**: `http://localhost:8000`

## 🎨 Customization

### Colors
Update CSS custom properties in `styles.css`:
```css
:root {
    --primary-brown: #8B4513;
    --instacart-green: #43B02A;
    --warm-orange: #FF8C42;
    /* ... */
}
```

### Content
- Modify text content directly in `index.html`
- Update testimonials, statistics, and feature descriptions
- Customize Bruno's quotes in `script.js`

### Animations
- Adjust animation timing in CSS keyframes
- Modify interaction behaviors in JavaScript
- Add new animations following existing patterns
